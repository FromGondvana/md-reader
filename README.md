# MD Reader

Лёгкий десктоп-ридер для Markdown-файлов ваших проектов: дерево файлов, оглавление,
переходы по ссылкам, поиск по проекту. Стек: **Go (Wails v2) + TypeScript + Vite**.
Итог — один exe ~14 МБ, внешних зависимостей в рантайме нет (только WebView2,
который уже встроен в Windows 10/11).

## Возможности

- **Дерево файлов** проекта: только `.md`/`.markdown`, папки разворачиваются,
  позиция запоминается; `node_modules`, `.git`, `dist` и прочий мусор скрыты.
- **Рендеринг Markdown**: таблицы (с горизонтальной прокруткой), код-блоки
  с подсветкой и кнопкой «Копировать», чек-листы, цитаты, якоря у заголовков.
- **Кириллические якоря**: слаги как на GitHub (`#экраны` работают, в т.ч.
  ссылки между файлами вида `[x](other.md#экраны)`).
- **Перекрёстные ссылки** между файлами — навигация внутри ридера,
  история назад/вперёд; внешние ссылки — в системный браузер.
- **Оглавление** текущего файла справа с подсветкой активного раздела.
- **Поиск по всем файлам** (Ctrl+Shift+F): сниппеты, номера строк, переход
  к совпадению с подсветкой.
- **Быстрый переход к файлу** (Ctrl+P) с учётом недавних.
- **Авто-refresh**: слежение за файловой системой (fsnotify) — правки файла
  или дерева подхватываются сами.
- **Темы**: тёмная/светлая, запоминаются. Масштаб: Ctrl+= / Ctrl+- / Ctrl+0.
- **Drag&drop**: перетащите папку или `.md`-файл в окно — откроется.
- **Открыть с помощью**: `md-reader.exe путь\к\файлу.md`; повторный запуск
  exe открывает файл в существующем окне.
- Настройки (последний проект, недавние, тема, ширина сайдбара) — в
  `%APPDATA%\md-reader\settings.json`.

## Горячие клавиши

| Клавиши       | Действие                     |
| ------------- | ---------------------------- |
| `Ctrl+P`      | Быстрый переход к файлу      |
| `Ctrl+Shift+F`| Поиск по всем файлам проекта |
| `Alt+←`/`Alt+→`| Назад / вперёд по истории   |
| `Ctrl+B`      | Показать/скрыть дерево       |
| `F5`          | Обновить дерево и файл       |
| `Ctrl+=`/`Ctrl+-`/`Ctrl+0` | Масштаб         |
| `Esc`         | Закрыть оверлей              |

## Запуск

Готовое приложение: **`build/bin/md-reader.exe`** — просто двойной клик.

### Разработка

Нужны Go 1.21+ и Node.js 18+.

```bash
wails dev        # dev-сервер + окно приложения с HMR
```

Фронтенд отдельно можно открыть в браузере на http://localhost:34115
(привязки Go работают; для быстрой проверки есть параметр `?root=C:/путь/к/проекту`).

### Сборка

```bash
wails build      # → build/bin/md-reader.exe
node scripts/genicon.mjs   # перегенерировать иконку (build/appicon.png)
```

## Структура

```
main.go, app.go        — окно Wails и привязки (диалоги, буфер, заголовок)
tree.go                — дерево .md-файлов (LoadTree)
files.go               — чтение файлов и картинок (ReadFile, ReadFileBase64)
search.go              — поиск по содержимому и по именам (SearchAll, SearchFiles)
watch.go               — слежение за изменениями (fsnotify → событие fs:changed)
settings.go            — сохранение настроек в %APPDATA%
frontend/src/
  main.ts, project.ts  — запуск, топбар, клавиатура, события Go
  state.ts, api.ts     — состояние и типизированные привязки
  markdown/            — markdown-it, слаги (кириллица), ссылки
  ui/                  — дерево, ридер, оглавление, оверлеи, тосты
  styles/              — темы (CSS-переменные), layout, типографика
```
